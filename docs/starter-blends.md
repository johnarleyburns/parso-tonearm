# Starter Blends: release-backed streaming

Six curated blends (36 tracks, 30 edges) stream from the immutable GitHub Release
`starter-blends-aac-v2` (`<releaseTag>/<trackID>.m4a`, AAC-LC; Jamendo content mirrored under the
owner's direct licensing agreement with Jamendo). Nothing is bundled, pre-downloaded,
planned or analysed at runtime.

| Piece | Where |
| --- | --- |
| Runtime catalog (36 tracks, 30 plans, copied verbatim from the release JSON) | `Sources/Domain/Mix/StarterBlendRuntimeData.swift`, generated by `tools/starter-blends/generate-runtime-data.py` |
| Pack identity, plan types and their resolution to seconds | `Sources/Domain/Mix/StarterBlendRelease.swift` |
| Catalog lifecycle `unindexed → blendEligible → edgePlanned` + facts + edge plans | migration `v35`, `LibraryStore+BlendCatalog.swift`, `BlendCatalog.swift` |
| Saved blend = pack identity + ordered concrete plans | `BlendDocument.pack`, `BlendDocument.Edge.plan`, `BlendReplay.starterRequest` |
| Range reader (206 + `Content-Range`, bounded LRU chunks, retries/backoff, cancel) | `ReleaseRangeReader.swift` |
| Byte-range M4A decode (CoreAudio `AudioFile` callbacks → `ExtAudioFile`) | `ReleaseM4ADeckSource.swift` |
| Two bounded decks, plan execution (bass swap / double drop / phrase cut), live output | `StarterStreamPlayer.swift`, `BoundedDeckMixer.swift` |
| Card → request → `AudioPlayer.playStarterBlend` → stream | `StarterBlendPlayback.swift`, `AudioPlayer+StarterStream.swift` |

Truthfulness: a loaded blend publishes all five edges as planned and ready. If an asset cannot be read the
stream stops, the card says exactly why (retryable or permanent), and the rest plays in order on the ordinary
player with no blend claimed. The resident whole-file decks (`MixDeckPlayer`) are never used for a Starter
session, including that fallback.

Keep Playing for a Starter session continues from blend-eligible catalog tracks, planning each new edge from the
stored facts only (`CatalogEdgePlanner`) and persisting it; it does not consult the similarity model.

Known limits: the incoming tempo is applied by resampling (pitch moves with tempo, at most a few percent), not by
a keylocked stretch; all assets of one session must share a sample rate (an edge that does not is reported as
unavailable).
