# Translation reviewer kit

Switch Platterhead's language from the iPhone Settings app: Settings → Apps → Platterhead → Language.

Visit Listen → Build a Mix → Generate → Mix Preview, then Settings → Appearance and Now Playing. Check the default and larger text sizes in each appearance.

Report fixes with a screenshot, the English source string, and suggested wording. The catalog marks first-pass translations `needs_review` so every reviewer change remains visible.

What to test: German — Prüfen Sie Mix-Erstellung, Erklärungen und große Schriftgrößen. Chinese — 请检查创建混音、说明和大字号。Spanish — Comprueba la creación de mezclas y las explicaciones. French — Vérifiez la création des mix et les explications. Japanese — ミックスの作成と説明、大きな文字を確認してください。Portuguese (Brasil) — Verifique a criação de mixagens e as explicações.
