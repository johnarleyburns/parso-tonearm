# Parso Platterhead HTML Mockups

Open `index.html` to navigate all views. Every view is a standalone HTML file with embedded CSS and no external dependencies.

Coverage rule: every macOS screen in the MVP spec has an HTML mockup, and every changed or new iOS/watchOS companion view must have one before implementation.

## Mac views (10)
First launch/iCloud, library, ingestion/analysis, semantic vibe search, track preparation, DJ workspace/stems, recording completion, recorded mixes, MIDI/audio routing, settings/iCloud.

## iOS additions/modifications (5)
Modified Listen home, Mac Mixes library, mix detail, offline now playing, iCloud/Mac sync settings.

## watchOS additions/modifications (0)
No watchOS views are added or materially changed by this MVP. Future watchOS mix surfaces require `watch/*.html` mockups and index entries.
