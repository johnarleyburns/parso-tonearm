§42.2 Library home (iPhone). The existing player's home with two additions: the semantic search field promoted to the top, and a "Playlists made for you" shelf. This is the primary surface for most users and it is entirely free — remote libraries included, with no tier badge except the one confirming there isn't one (FR-LIB-7). The Perform tab is present and unlocked-looking in the bar; tapping it reaches the paywall in context (§42.10), never an interstitial (FR-STORE-6). Everything here works with no account, no iCloud and no network.
