§41.1a The genre picker · FR-LIB-9 / FR-LIB-10. GenrePickerView ▸ GenrePickerModel ▸ JamendoGenreProvider, SourceRepository. Free. M5's exit is a performance — pick a genre, build two deck playlists, mix, record, listen, share — and it stalls at step one for the user this app most wants: a new DJ with no library. The existing ten providers all assume you already own a Plex server or a folder of files. A genre library inverts the unit of subscription: you subscribe to a genre, not a server, and each genre is an independent library with its own list (§18A.3), because that is how DJs think about practice material. Three rules visible here. Skip is equally weighted — a user with their own collection must not be herded through a picker they don't need. No account is requested, preserving §41.1's promise; the optional-credentials checkbox is collapsed and gates nothing (§18A.2). And licensing is stated once, up front, in one sentence rather than buried in settings — attribution follows the track into the mix's cue-sheet automatically (§18A.5), which is what makes a practice set safe to post. Source note. The Free Music Archive was the original candidate and cannot be used: FMA shut down their public API and their app-developers page prohibits both hotlinked playback and scraped browsing. The shipped source is the Jamendo API, which permits exactly this pattern and provides the popularity ordering this screen promises (§18A.2). The client_id is an application credential registered once by the owner — not a user login.
