§41.9a DJ workspace — jog module. WorkspaceView ▸ WorkspaceModel ▸ PerformanceEngine, TelemetryPump. Pro. §41.9 is unchanged above the fold; what changes is that each deck's lower third becomes a module slot — JOG · STEMS · PADS · FX — remembered per deck, so a user who wants the traditional surface gets it and a user who mixes with stems keeps the layout the spec already shows. The jog is 248 pt (≈48 mm at this iPad's 131 pt/in, so a whole-hand control rather than the iPhone's thumb control) and splits by radius the way hardware splits by capacitive surface: platter = position (scratch on Deck A's vinyl mode, nudge on Deck B's CDJ mode) and ring = pitch bend, with ± bend buttons for people who would rather not. The white marker is track position, the ghost marker is the other deck's beat phase, and the centre beat-phase meter is the same readout summed — the design's one claim to being better than a controller, since a controller cannot show you the other deck's phase at all. Holding LOOP opens a release-to-commit flyout: sliding out of it cancels, so a mistimed grab never changes a loop mid-phrase. One honest asymmetry, stated because it affects the design rather than the marketing: iPad has no Taptic Engine, so the per-beat jog detents that make the iPhone's smaller jog usable are iPhone-only; the iPad compensates with size and with the bar/beat readout inside the platter.
